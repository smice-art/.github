# Security Policy

## Supported Versions

We actively support and maintain the latest releases of our Blender add-ons and Python scripts. Please ensure you are using the most recent version before reporting an issue.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest| :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or a critical bug that could compromise user systems 
(e.g., unexpected script executions or data handling issues), please do **NOT** open a public issue. 

Instead, please report it privately by contacting us through **[ice.smice@gmail.com]**.

We will investigate the report and aim to provide a fix as quickly as possible. 
Thank you for helping keep this creative space safe for everyone!
